# Contributing to device-passport

Thank you for your interest in contributing to `device-passport`!

## Development Workflow

1. Clone repository:
   ```bash
   git clone https://github.com/webkubor/device-passport.git
   cd device-passport
   ```
2. Install dependencies:
   ```bash
   bun install
   ```
3. Run tests:
   ```bash
   bun test
   ```
4. Build library:
   ```bash
   bun run build
   ```

## Pull Request Guidelines

- Ensure zero contradictions in hardware/OS mappings.
- Add unit tests for any new features or edge cases.
- Follow existing code style and semantic commit conventions.
